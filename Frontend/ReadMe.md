# SciGURU Frontend

## Overview
Frontend implementation for the SciGURU scientific explanation platform.

## Technology Stack
- **Component Design:** WIX drag-and-drop interface
- **Custom Logic:** JavaScript (SciGURU team)

## Structure
- `/Code/Pages/` - Page-specific JavaScript modules
- `/Code/backend/` - Backend services (jsw files)
- `/Code/public/` - Shared frontend components
- `/animations/` - UI animation assets

## Key Features
- Interactive chat interface for scientific Q&A
- Real-time model response polling
- Multi-model support (Alpha, Beta, Gamma, Delta, Phi)
- Markdown rendering for formatted responses
- User authentication and session management
